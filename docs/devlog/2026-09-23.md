## Decisions

- 개인용 한 PC 앱이라 서버 없이 브라우저 저장을 사용했다. 나중에 저장 방식이 바뀌어도 기록 구조를 유지할 수 있도록 JSON 백업에 스키마 버전을 넣었다.
- 영어·한국어 비교에서 총점과 재작업 건수는 중앙값, Structure 개별 항목은 소수점 첫째 자리 평균으로 표시했다. 시간 구간은 실제 분의 평균으로 환산하지 않고 순서형 중앙 구간으로 표시했다.
- 시안에 없는 Problem Type·백업 기능은 입력 속도와 시안의 밀도를 유지하도록 기존 카드·버튼 스타일로 확장했다. 작은 화면에서는 저장 바를 두 줄로 배치했다.
- 초기 시각 검증에서 저장 바가 화면 아래로 밀리는 문제를 발견해 앱 높이와 독립 스크롤을 수정했다. 브라우저의 favicon 404 오류도 데이터 URL 아이콘으로 해결했다.
- npm 감사에서 확인된 개발용 Vitest 취약 버전을 수정 버전으로 올렸고 재검사에서 취약점 0건을 확인했다.
- Playwright 테스트 파일 추가 후 Vitest가 이를 단위 테스트로도 수집해 실패했다. Vitest의 수집 범위를 src의 단위 테스트로 제한하고 두 테스트 명령을 다시 통과시켰다.
