## Decisions - 폴더 자동 JSON 백업

- 브라우저 보안상 절대 경로를 코드로 직접 지정할 수 없으므로, 폴더는 사용자가 선택하고 앱은 그 권한을 재사용한다. 공개 UI·코드에는 Windows 사용자명 대신 Documents/EDM만 안내한다.
- EDM이 아닌 이름의 폴더를 고르면 한 번 더 확인하되, 경로 이동 등 예외 상황을 위해 사용자가 의도적으로 다른 폴더를 선택할 수 있게 했다.
- 시작 시 파일이 현재 기록과 다르면 빈 브라우저 데이터로 기존 JSON을 덮어쓰지 않는다. 실제 파일 쓰기가 성공한 뒤에만 자동 백업 완료로 표시한다.
