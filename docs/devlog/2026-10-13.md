# 2026-10-13 SOP Score Tracker Development Log

## Work Summary

감수 후 분류·비교하던 기록을 새 SOP 작업 전에 참고하도록 Pattern Explorer를 추가했다. J님과 계획 및 설명용 시안을 검토한 뒤, MBTI와 Problem Type은 공간을 덜 차지하는 드롭다운으로 결정했다. 기존 데이터는 유지하고 조회 방식과 입력 폼의 구획을 변경했다.

## Work Completed

- Dashboard 최상단에 독립적인 MBTI·Problem Type AND 필터, 리뷰 수·차수 구성, 빈 결과 해제 동작을 추가했다.
- 선택한 Type을 제외한 동반 Type, 구조 0·1점 항목, 실제 Major Rework와 Revision Focus를 집계한다. 상위 항목은 3개로 제한하고 분모는 선택된 리뷰 수를 사용한다.
- 기존 구간형 중앙값을 유지하며 차수별 리뷰 수·시간을 펼쳐 볼 수 있게 했다. 120m+를 정확한 관측값이나 예상 시간으로 변환하지 않는다.
- 1–4건은 사례를 먼저 보여주고 첫 사례를 펼치며, 5건 이상은 집계 요약과 최근 5건을 표시한다. 사례에는 차수, 실제 점수·작업·메모 및 하위 유형을 표시한다.
- 사례 읽기와 Edit을 분리했다. 편집 진입 시 폼의 미저장 변경을 확인하고, 취소하면 작성 내용을 유지한다. 저장·복원·편집 취소 후에는 변경 비교 기준도 초기화한다.
- Review Info / Draft Diagnosis / Revision Outcome으로 기존 필드를 재배치했다. Structure Score와 Major Rework를 분리하고 시간 선택은 전체 폭을 사용한다.
- 넓은 화면은 좌측 입력·우측 조회, 1100px 이하에서는 탐색·기존 통계·입력 순서로 배치했다. 좁은 화면에 입력 이동 바로가기를 추가하고 모바일 스크롤을 연결했다.
- 단위·데이터베이스 테스트 46개, Chrome 브라우저 테스트 34개, TypeScript 및 프로덕션 빌드가 통과했다. Chrome 100% 줌의 2048·1280·900·390px 화면에서 필터·사례·편집·가로 넘침을 확인하고 외부 QA 폴더에 화면을 저장했다.

## Decisions

- MBTI는 J님이 지정하는 글 패턴 그룹이며 기존 8개 값과 순서를 유지한다. 기본 집계는 모든 차수의 Review 단위이며 학생 이름으로 중복 제거하지 않는다.
- Explorer는 기존 통계 필터와 독립적으로 동작한다. 기존 통계의 Filters 컨트롤은 해당 영역으로 옮겨 적용 범위를 명확히 했다.
- 저장 스키마·저장 키·JSON·CSV 및 백업 형식은 변경하지 않았다. 조회 결과·선택·펼침 상태는 저장되는 Review 데이터에 추가하지 않는다.
- 소표본 표시 기준은 통계적 신뢰도 판단이 아니다. 전체 대비 비교, 자동 대응 추천, 효과 판정, 예상 시간 계산은 이번 범위에서 제외했다.
- 과거 Revision Focus 누락 값이 none으로 보정되는 기존 호환 동작을 유지한다. 도움말에서 이를 설명하고 none 빈도로 수정 불필요를 추론하지 않는다.

## Current Status

계획한 기능은 로컬 구현 및 검증을 완료했다. 첫 Vitest 실행은 Windows 샌드박스의 realpath EPERM 오류로 테스트 실행 전에 중단됐고, 승인된 실행 경로에서 전체 46개가 통과했다. 브라우저 검증은 Browser 플러그인이 없어 기존 Playwright의 실제 Chrome 채널을 사용했다. 마지막 시간 선택 배치 변경 후 Explorer·가독성 관련 10개 테스트와 빌드를 다시 실행해 통과했고, 각 시간 버튼의 넘침도 확인했다. 백업 관련 검증은 기존 로컬·모의 테스트이며 실제 클라우드 쓰기나 운영 데이터 변경은 수행하지 않았다. 커밋·푸시·배포는 하지 않았다.

## Work Completed - 세 화면 분리와 사례 조회 통합

- Explorer에 Problem Type·취약 Structure·Major Rework의 가로 막대, Revision Focus의 누적 막대, MBTI 분포의 가로 막대를 추가했다. MBTI 비율은 선택된 기록 중 분류 값이 있는 Review만 분모로 사용한다.
- Previous Reviews의 별도 텍스트 상세를 제거했다. 두 화면은 같은 테이블 컴포넌트를 사용하고, Explorer에는 선택 조건에 일치하는 기록을 표시한다.

- Statistics는 기존 Review Analysis 내용만 표시한다. 탭 순서는 Structure details / Problem patterns / Language comparison이고 처음 선택되는 탭은 Structure details다.
- 단위·DB 테스트 46개, 최종 Chrome 테스트 33개, TypeScript·프로덕션 빌드가 통과했다. 2048·1280·900·390px에서 화면 전환, 차트, 전체 20건 예시 테이블, 조회·편집·복귀, 가독성과 넘침을 검증했다. 화면 기록은 저장소 밖 QA 폴더에 보관했다.
