# 2026-11-28 Draft Pattern Log Development Log

## Work Summary

J님이 기존 리뷰를 직접 재분류할 수 있도록 MBTI 선택지를 8개에서 13개로 늘렸다. 다섯 그룹을 I와 E로 나누고 세 그룹은 공통으로 유지했다.

## Work Completed

- `xNTJ`, `xNTP`, `xNFJ`, `xNFP`, `xSFJ`를 각각 `INTJ`, `INTP`, `INFJ`, `INFP`, `ISFJ`로 변환하는 규칙을 추가했다.
- `ENTJ`, `ENTP`, `ENFJ`, `ENFP`, `ESFJ`를 추가하고 `xSTJ`, `xSFP`, `xSTP` 및 미지정을 유지했다. 리뷰 선택지, 대시보드 필터, Pattern Explorer, MBTI 분포가 새 목록을 공통으로 사용한다.
- 2048px 화면에서도 분포 차트가 13개 항목을 두 열에 표시하도록 조정했다.

## Decisions

- 브라우저 저장 기록과 JSON·폴더·클라우드 백업이 공유하는 읽기 단계에서 변환한다. 기록 ID와 수정 시각을 보존하고, 이후 저장이나 내보내기에 변환된 값이 사용되도록 했다. E 유형 지정은 리뷰 편집에서 수동으로 한다.

## Current Status

- 단위·DB 테스트 53개, Chrome 브라우저 테스트 36개 전체 및 프로덕션 빌드가 통과했다. 변환 대상 5개, 공통 그룹 3개, 기존 백업과 새 E 유형의 저장 호환성을 검증했다.
