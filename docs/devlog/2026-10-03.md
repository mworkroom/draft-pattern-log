# 2026-10-03 Draft Pattern Log Development Log

## Work Summary

Background가 경력 단계와 고용 분야를 섞고 있어 별도 통계 분석이 어려웠다. Career Stage와 Sector를 독립적인 선택·저장·필터 차원으로 분리했다.

## Work Completed

- 폼의 Background를 Career Stage와 Sector 드롭다운으로 교체했다. 요청된 선택지와 순서를 적용하고 기본값은 모두 Not specified로 유지했다.
- 모델과 새 기록 저장, 편집 복원, JSON 백업, CSV를 두 독립 필드로 변경했다. CSV 열은 `career_stage`, `sector`이다.
- 공통 `parseBackup()` 경로에서 기존 localStorage, 수동 JSON 복원, 폴더 백업의 Background를 변환한다. Fresh Graduate는 Career Stage에만, Corporate/Public Sector/NGO/Other는 Sector에만 매핑한다. NGO는 NGO / Nonprofit으로 바꾸고 누락·빈 값·Not specified는 양쪽 빈 값으로 복원한다.
- Dashboard에 두 필터를 추가해 기존 지표, 수정 패턴, 리뷰 목록에 각각 적용한다. 두 필터 동시 선택도 지원한다.
- 1280px에서 긴 Career Stage 필터 선택지가 잘리는 것을 실제 글자 폭으로 확인했다. 필터 그리드를 최소 220px 기준 자동 줄바꿈으로 변경해 글자 크기를 유지했다.
- 모든 기존 Background 매핑, 새 값 우선 보존, 잘못된 값 거부, 백업 왕복, CSV 열, 독립·교차 필터와 수정 통계, 브라우저 저장·재편집·마이그레이션 검사를 추가·갱신했다.

## Decisions

- 두 값은 서로 유추하지 않는다. 기존 Background만으로 알 수 없는 차원은 Not specified이며, 합성 분류를 만들지 않는다.
- 기존 저장 키와 schemaVersion 1은 유지하고 읽기 시 정규화한다. 새 필드가 이미 있으면 빈 값까지 보존하며 Background로 덮어쓰지 않는다. 다음 저장·백업에는 Background를 제거한 두 필드가 기록된다.
- 경력 연수 기준은 코드 주석의 분류 지침으로만 남겼다. 폼에서는 요청된 명칭만 표시한다.
- 기존 Type 7 도움말 편집을 보존했다. 그 문구와 맞지 않던 단위·브라우저 테스트의 기대값을 현재 문구에 맞췄다.
