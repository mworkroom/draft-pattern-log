# 2026-11-24 Draft Pattern Log Development Log

## Work Summary

Type 4의 설명을 갱신하고, 기존 Type 6과 동일한 체크박스 디자인·복수 선택 동작의 Narrative / Indirect 하위분류를 추가했다. 과거 Type 4 기록에는 하위분류를 추정하여 부여하지 않고 미지정으로 유지한다.

## Work Completed

- Type 4 설명을 `핵심 내용을 직접 전달하기보다 서사적 전개나 간접적인 연결에 의존하여 단락의 역할과 논리적 흐름이 불명확해짐`으로 변경했다.
- `Narrative / Indirect subtype *`에 Delayed-Point Narrative와 Question-Driven Narrative를 요청된 순서·설명 그대로 추가했다. Type 4 선택 시에만 표시되며 둘 다 선택할 수 있다.
- 독립 배열 `narrativeSubtypes`와 키 `delayedPointNarrative`, `questionDrivenNarrative`를 추가했다. 신규·편집 저장에서 Type 4가 선택되어 있으면 하나 이상 필요하며, Type 4 해제 시 해당 배열만 비운다.
- 저장·복원·편집·JSON 백업과 CSV의 두 선택 여부 열에 반영했다. 공통 `parseBackup()`에서 필드가 없는 기존 기록을 빈 배열로 정규화한다. 이미 존재하는 값은 보존하고 잘못된 값·중복·다른 상위 유형에 연결된 값을 거부한다.
- Statistics와 Pattern Explorer에 두 하위분류 및 Not specified (Type 4)의 건수 차트를 추가했다. 분모는 현재 선택된 Type 4 리뷰 수이며 복수 선택으로 합계가 분모를 초과할 수 있다.
- 상단 Filters와 Pattern Explorer에 하위분류 필터를 추가했다. 미지정 필터는 Type 4 기록에만 적용하며 다른 유형의 빈 배열은 포함하지 않는다. 기존 유형·MBTI·차수 필터와 함께 사용할 수 있다.
- 새 필터의 긴 선택지를 읽을 수 있도록 Explorer 필터 영역을 최소 220px 기준으로 줄바꿈했다.

## Decisions

- `type4` 키와 기존 분류는 유지한다. 기존 Type 4의 하위분류 누락·빈 배열은 읽기와 백업에서 허용해 과거 기록이 깨지지 않도록 했다. 이를 편집하여 다시 저장할 때는 화면의 필수 표시대로 하위분류를 선택해야 한다.
- 누락값과 잘못된 값을 구분한다. 과거 기록을 임의로 Delayed-Point Narrative 등으로 재분류하지 않고 조회 화면에 Not specified를 표시한다.
- Type 6의 모델·검증·체크박스 동작과 다른 유형의 분류 규칙은 유지한다. Type 4와 Type 6의 배열은 서로 독립적이다.
- 기존 schemaVersion 1·저장 키를 유지하고 공통 백업 검증 경로를 활용했다. 별도 DB 스키마 변경은 필요하지 않으며 운영 데이터에 쓰지 않았다.
- 회귀 검사에서 Explorer의 기존 소표본 비율 숨김 규칙과 새 차트가 충돌한 것을 발견했다. 새 차트도 기존 규칙을 따르도록 수정하고 Type 4 기록이 없는 경우에는 0/0 대신 빈 상태 안내를 표시한다.
