# 2026-10-08 Draft Pattern Log Development Log

## Work Summary

학생/리뷰에 I/E를 구분하지 않는 MBTI 8개 그룹을 선택적으로 기록하고, Dashboard 분포와 Recent Reviews에서 분류별 기록을 확인할 수 있도록 추가했다. 동일 학생의 여러 차수 집계 방법을 질문했고, J님이 선택한 리뷰 기록별 집계를 적용했다.

## Work Completed

- 폼에 기본 선택이 없는 MBTI 드롭다운을 추가했다. 선택지는 xNTJ, xNTP, xNFJ, xNFP, xSTJ, xSTP, xSFJ, xSFP 순서이며 미지정 상태로 저장·해제할 수 있다.
- `mbti`를 별도 필드로 저장하고 기존 기록 편집에서 유지한다. 공통 모델·입력 검증·저장 검증·JSON 백업·CSV 열을 함께 갱신했다.
- 기존 기록에서 MBTI 필드가 없으면 빈 값으로 정규화한다. 현재 선택값은 보존하고 16개 유형 문자열이나 잘못된 값은 거부한다.
- Dashboard에 8개 그룹별 리뷰 건수와 비율을 보여주는 작은 분포 카드를 추가했다. 현재 필터에 포함된 MBTI 지정 리뷰만 분모에 포함하며 지정 데이터가 없으면 건수·비율을 0으로 표시한다.
- Recent Reviews의 Problem Type 옆에 MBTI 필터를 추가했다. 상단 Filters와 공통 상태를 사용하므로 목록·통계가 함께 갱신된다. All groups와 Not specified를 지원하며 다른 필터와 조합할 수 있다.
- 두 데스크톱 폭에서 필터 줄바꿈과 카드 정렬을 검증했다. 글자를 줄이지 않고 좁은 화면에서는 검색창이 다음 줄로 이동한다.

## Decisions

- J님의 확인에 따라 같은 학생의 1차·2차·3차도 각각 1건으로 집계한다. 이름으로 중복 제거하지 않으며 UI에도 리뷰 단위와 미지정 분모 제외 기준을 표시했다.
- I/E 유형 선택지와 자동 성격 추정, 설명, 아이콘, 별도 분석 페이지는 추가하지 않았다. 요청된 8개 문자열만 수동 선택한다.
- 기존 schemaVersion 1과 저장 키를 유지하고 `parseBackup()`에서 누락값만 보정한다. 기존 폴더·Supabase 클라우드 백업이 리뷰 JSON 전체를 저장하므로 DB 스키마 변경 없이 같은 호환성 경로를 사용한다.
- MBTI 필터를 5건 미리보기보다 먼저 적용해 미리보기에 없던 기록도 조회되도록 했다. 분포는 기존 Dashboard와 같이 공통 필터를 반영하며 이름 검색은 기존처럼 목록에만 적용한다.
