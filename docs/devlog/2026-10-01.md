# 2026-10-01 Draft Pattern Log Development Log

## Work Summary

SOP가 연구계획서나 문항별 답변지처럼 다른 문서 장르로 작성된 경우를 구조 점수와 별개로 기록하도록 Type 6을 추가했다.

## Work Completed

- `Type 6 — Genre Mismatch`를 Type 5와 Unclassified 사이에 추가하고, Research Proposal Style과 Prompt-Response / Q&A Style을 별도의 체크 항목으로 만들었다.
- Type 6 선택 시 하위 유형을 하나 이상 고르게 하고, Type 6을 해제하면 하위 선택을 지우도록 했다. 두 하위 유형은 동시에 선택할 수 있다.
- 저장 기록, 이전 JSON 백업 복원, CSV 열, Problem Type Distribution 및 Dashboard 필터에 새 유형이 반영되도록 했다.
- 현재 `Background` 선택지가 `NGO`로 바뀐 뒤 남아 있던 이전 테스트 기대값을 수정했다. 실제 Background 선택지는 변경하지 않았다.
- 빌드, 단위 테스트 19개, Chrome 브라우저 테스트 12개가 통과했다. 1280px 및 2048px 화면에서 하위 유형 영역의 글자 크기와 가로 넘침을 확인했다.

## Decisions

- Type 6은 점수나 Major Rework에서 자동 추론하지 않는다. 장르 불일치가 확인된 경우에만 직접 선택하며 Type 1–5와 함께 선택할 수 있다.
- 이전 schemaVersion 1 기록에 새 하위 유형 속성이 없으면 빈 목록으로 복원한다. 새 Type 6 기록에는 하위 유형을 요구해 유형별 의미를 보존한다.
- 두 장르가 한 초안에 동시에 나타날 수 있으므로 하위 유형은 복수 선택을 허용한다. 기존 Problem Type 카드 스타일을 재사용했다.
