# SOP Score Tracker

SOP 1차 감수 후 학생 초안의 구조 점수, 대규모 수정, 문제 유형과 작업 시간을 기록하는 개인용 데스크톱 웹앱입니다.

## 사용

- 배포 주소: https://mworkroom.github.io/draft-pattern-log/
- 화면 왼쪽에서 평가를 입력하고 **Save Review**를 누릅니다. 오른쪽 Dashboard는 즉시 갱신됩니다.
- 학생 이름을 누르면 기존 기록을 수정할 수 있고, 행 끝의 휴지통 버튼으로 삭제할 수 있습니다.
- **Filters**로 감수일, 언어, Level, Field, School Tier, Problem Type을 조합합니다. 분석 탭에서 언어 비교, 항목별 점수, 문제 유형을 확인합니다.
- 처음 한 번 **백업 폴더 선택**을 눌러 문서(Documents) 폴더 안의 `EDM`을 선택합니다. 브라우저 보안상 웹앱이 이 경로를 코드만으로 자동 지정하거나 전체 경로를 검증할 수는 없습니다. Chrome이 폴더 접근을 다시 요청하면 **접근 다시 허용**을 누릅니다.
- 폴더가 연결된 상태에서는 기록 저장·수정·삭제 때 `sop-score-tracker-current.json`을 자동 갱신합니다. 그날 첫 갱신 전 파일은 `sop-score-tracker-history-YYYY-MM-DD.json`으로 남깁니다. 상단 안내에서 실제 자동 백업 성공·실패를 확인할 수 있습니다.
- 브라우저 기록과 폴더 JSON이 다르면 어느 쪽도 자동 덮어쓰지 않습니다. 폴더 파일에서 복구하거나, 기존 파일의 안전 사본을 만든 뒤 현재 브라우저 기록으로 갱신할 수 있습니다. 사이트 데이터를 지웠다면 EDM 폴더를 다시 선택하고 **폴더 파일에서 복구**를 누릅니다.
- 헤더의 **Backup**은 폴더 연결과 별개로 전체 기록을 JSON으로 수동 다운로드합니다. 옆의 업로드 아이콘은 JSON 복원, 다운로드 아이콘은 CSV 내보내기입니다.

학생 기록은 서버나 GitHub 저장소에 올라가지 않습니다. 기본 저장소는 이 웹주소를 연 브라우저 프로필의 localStorage이며, 폴더를 선택한 경우 별도 JSON도 저장됩니다. 같은 mworkroom.github.io 도메인의 다른 페이지와 브라우저 저장공간을 공유합니다. 다른 브라우저·프로필·PC로 자동 동기화되지 않습니다. 브라우저의 사이트 데이터를 지우면 기록과 기억된 폴더 연결이 사라질 수 있지만, 디스크에 성공적으로 저장된 JSON 파일은 남습니다. 파일 쓰기 실패나 권한 해제 시 자동 백업은 중단되므로 상단 상태를 확인하고, 별도 수동 백업도 유지해 주세요. JSON·CSV 파일에는 학생 이름과 메모가 포함되므로 백업 폴더의 접근·동기화 범위를 확인해 주세요.

## 개발

Node.js 24에서 npm ci로 의존성을 설치하고, npm run dev로 실행합니다. npm test와 npm run build로 검증합니다.

로컬 개발 주소는 http://127.0.0.1:5173/draft-pattern-log/ 입니다. main에 푸시하면 GitHub Actions가 검사와 빌드를 마친 뒤 GitHub Pages에 배포합니다. 앱은 정적 파일만 배포합니다.
